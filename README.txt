1. Neues GitHub-Repository anlegen, ALLE Dateien (auch den Ordner .github) hochladen.
2. Reiter "Actions" -> Workflow "build" laeuft automatisch (oder "Run workflow").
3. Fertigen Lauf anklicken -> unten "Artifacts" -> glassmod-jar herunterladen.
4. .jar zusammen mit Fabric API in den mods-Ordner (Minecraft 1.21.11, Fabric).
Falls der Build an Versionen scheitert: gradle.properties mit fabricmc.net/develop abgleichen.
